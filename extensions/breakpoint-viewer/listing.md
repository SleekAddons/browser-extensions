# Breakpoint Viewer: store listing

Paste into the Chrome Web Store dashboard (Store listing > Description) and
AMO Developer Hub (Edit Product Page > Summary, Description). The short
summary is the manifest description (`extDescription` in `locales/*.json`) and
ships with the next version; on AMO it also has to be pasted into Summary.

## Summary (132 characters max)

```text
See the active CSS breakpoint and viewport width on any site. Presets for Tailwind CSS, Bootstrap, Bulma, Foundation or custom.
```

## Description

```text
Breakpoint Viewer shows which CSS breakpoint is active on any website. A small badge in the corner of the page shows the current breakpoint (sm, md, lg, xl and so on), its min-width and the viewport width in pixels, and updates live as you resize the window. Made for testing responsive design with Tailwind CSS, Bootstrap, Bulma, Foundation or your own media queries.

FEATURES
• Live badge with the breakpoint name, its min-width and the screen width
• Presets for Tailwind CSS, Bootstrap, Bulma and Foundation
• Custom breakpoints with your own names, widths and colors
• Badge in any corner of the page
• Show it on all sites, only on the sites you list (such as localhost), or everywhere except some
• Turn the badge on or off from the toolbar
• Works on any website and on your local dev server, without changing the page

HOW TO USE
1. Open any website or your local development server.
2. Resize the window or use the DevTools device toolbar. The badge shows which breakpoint applies.
3. Click the toolbar icon to pick a preset, edit breakpoints or move the badge.

WHO IT IS FOR
Front-end developers, web designers and QA testers who build or check responsive layouts and want to see the active media query at a glance, without opening DevTools.

PRIVACY
No account, no tracking. Settings stay in your browser and no data is sent anywhere.

OPEN SOURCE
The full source code is on GitHub: https://github.com/SleekAddons/browser-extensions
Bug reports and feature requests are welcome.
```
