# Pi-hole Manager: store listing

Paste into the Chrome Web Store dashboard (Store listing > Description) and
AMO Developer Hub (Edit Product Page > Summary, Description). The short
summary is the manifest description (`extDescription` in `locales/*.json`) and
ships with the next version; on AMO it also has to be pasted into Summary.

## Summary (132 characters max)

```text
Pi-hole in your toolbar: see stats, pause blocking for a few minutes, and allow or block the current site in one click.
```

## Description

```text
Pi-hole Manager puts your Pi-hole in the browser toolbar. See query stats, turn blocking on or off, disable it for a few minutes when a site breaks, and allow or block the current site's domain without opening the Pi-hole admin dashboard. Works with Pi-hole v6 and newer, and with several Pi-hole servers at once.

FEATURES
• Stats for each Pi-hole: total queries, blocked queries and percent blocked
• Enable or disable blocking with one switch, per Pi-hole or for all of them at once
• Disable blocking for 10 seconds, 30 seconds, 5 minutes or indefinitely, with a live countdown
• Check whether the current site is on your allowlist, denylist, regex rules or gravity blocklists
• Allow (whitelist) or block (blacklist) the current domain in one click
• Manage multiple Pi-hole instances, each with its own status and controls
• Copy the current domain

HOW TO USE
1. Click the toolbar icon and choose Add Instance.
2. Enter your Pi-hole address (for example http://pi.hole or http://192.168.1.2) and its API password.
3. Use the switches and the current site panel right in the popup.

WHO IT IS FOR
Pi-hole users who want quick control over network-wide DNS blocking, for example to unblock a broken site for a moment or to check why a domain is blocked.

PRIVACY
The extension talks only to the Pi-hole servers you add. Passwords are stored locally in your browser. No account required.

OPEN SOURCE
The full source code is on GitHub: https://github.com/SleekAddons/browser-extensions
Bug reports and feature requests are welcome.
```
