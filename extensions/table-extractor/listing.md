# Table Extractor: store listing

Paste into the Chrome Web Store dashboard (Store listing > Description) and
AMO Developer Hub (Edit Product Page > Summary, Description). The short
summary is the manifest description (`extDescription` in `locales/*.json`) and
ships with the next version; on AMO it also has to be pasted into Summary.

## Summary (132 characters max)

```text
Export HTML tables from any webpage to Excel (XLSX), CSV, JSON, XML or HTML. Preview the data, then download or copy in one click.
```

## Description

```text
Table Extractor exports tables from any webpage to Excel (XLSX), CSV, JSON, XML or HTML. It finds every HTML table on the page, shows a preview, and lets you download the file or copy the data to your clipboard in one click. No more selecting rows by hand and fixing broken formatting in your spreadsheet.

FEATURES
• Finds all tables on the current page automatically, with row and column counts
• Preview the first rows before you export
• Export to XLSX (Excel), CSV, JSON, XML and HTML
• Download as a file or copy to the clipboard, ready for Excel, Google Sheets or your code
• Rescan the page after it loads more data, without reloading

HOW TO USE
1. Open a page with a table, such as a Wikipedia article, a report or a dashboard.
2. Click the Table Extractor icon and pick a table.
3. Choose a format, then Download or Copy.

WHO IT IS FOR
Analysts, researchers, students, journalists and developers who need data from websites in a spreadsheet or a data file, without copy and paste or a scraper.

PRIVACY
Table Extractor reads a page only when you click its icon. Everything runs in your browser: no account, no tracking, and no data sent to any server.

OPEN SOURCE
The full source code is on GitHub: https://github.com/SleekAddons/browser-extensions
Bug reports and feature requests are welcome.
```
