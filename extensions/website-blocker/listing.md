# Website Blocker: store listing

Paste into the Chrome Web Store dashboard (Store listing > Description) and
AMO Developer Hub (Edit Product Page > Summary, Description). The short
summary is the manifest description (`extDescription` in `locales/*.json`) and
ships with the next version; on AMO it also has to be pasted into Summary.

## Summary (132 characters max)

```text
Block distracting websites with daily time limits and schedules. Stay focused and see how much time you spend on each site.
```

## Description

```text
Website Blocker helps you stay focused by blocking distracting websites. Block a site completely, give it a daily time limit, or block it only during the hours you choose, such as work or study time. Blocked pages are stopped before they load and show a short reminder of why instead.

FEATURES
• Block list: block social media, video, news or any other distracting sites
• Allow list mode: block everything except the sites you allow
• Daily time limits of 15 minutes, 30 minutes, 1, 2 or 3 hours, or a custom time, with the time left shown live
• Schedules: block sites on chosen days and hours, for example during work hours
• Usage stats for each site: time spent, allowed visits and blocked visits
• One switch to pause or resume all blocking
• Matches each site with and without www
• Pause a single rule without deleting it

HOW TO USE
1. Click the toolbar icon and add a site, for example example.com.
2. Optionally add a daily time limit or a schedule for it.
3. When you open a blocked site, a page tells you why it is blocked: on your block list, time limit reached, scheduled block, or not on your allow list.

WHO IT IS FOR
Students, remote workers and anyone who wants less procrastination and better browsing habits, with a simple site blocker instead of a full productivity suite.

PRIVACY
No account, no subscription, no tracking. Your rules and the time you spend on sites are stored only in your browser and never sent to any server.

OPEN SOURCE
The full source code is on GitHub: https://github.com/SleekAddons/browser-extensions
Bug reports and feature requests are welcome.
```
